GLOBAL CHAT RULES

Jaga komunitas tetap nyaman dan aman.

01

JANGAN SPAM

Jangan mengirim pesan yang sama secara berulang atau melakukan flood.

02

HORMATI MEMBER

Dilarang menghina, mengancam, atau mengganggu pengguna lain.

03

GUNAKAN CHAT DENGAN BIJAK

Jangan gunakan fitur chat untuk aktivitas yang merugikan pengguna lain.

04

MODERASI

Owner dan Developer dapat melakukan tindakan moderasi untuk menjaga komunitas.

terminal

COMMAND CENTER

Command tersedia menyesuaikan role akun.

USER COMMAND
/help ALL USER

Menampilkan bantuan command yang tersedia.

/rules ALL USER

Membuka aturan Global Chat.

/profile ALL USER

Menampilkan informasi profil akun sendiri.

/clear ALL USER

Membersihkan tampilan pesan secara lokal.

/dice ALL USER

Melempar dadu acak agar chat lebih seru.

/coin ALL USER

Memilih hasil acak antara HEADS atau TAILS.

OWNER & DEVELOPER COMMAND
/pin MODERATOR

Pilih atau balas pesan menggunakan tombol moderasi untuk menjadikannya pesan pin.

/setcd [detik] MODERATOR

Mengatur cooldown global pengiriman pesan.

/ban @username MODERATOR

Memblokir pengguna dari Global Chat sampai dibuka kembali.

/unban @username MODERATOR

Membuka blokir pengguna dari Global Chat.

/all [pesan] MODERATOR

Mengirim pengumuman tag seluruh pengguna Global Chat.

/unpin MODERATOR

Menghapus pesan yang sedang dipin.

/announce [pesan] MODERATOR

Mengirim pesan pengumuman khusus.

ATUR COOLDOWN

Masukkan waktu cooldown Global Chat dalam satuan detik.
