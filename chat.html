GLOBAL CHAT RULES

Jaga chat tetap aman dan nyaman.

block Dilarang Spam

Jangan mengirim pesan berulang, flood, atau spam.

sentiment_satisfied Gunakan Bahasa yang Baik

Hormati seluruh pengguna Global Chat.

image Foto Aman

Jangan mengirim gambar yang melanggar aturan platform.

warning Ikuti Moderator

Owner dan Developer berhak melakukan moderasi chat.

lock Ban Bersifat Permanen

Jika diban, kamu tidak dapat mengirim pesan sampai dibuka kembali.

terminal

USER COMMANDS

Bisa digunakan semua user.

waving_hand /me USER

Menampilkan status singkat tentang dirimu.

mood /random USER

Mengirim pesan random agar chat lebih seru.

info /help USER

Menampilkan bantuan command.

delete /del USER

Hapus pesan sendiri dengan membalas pesan tersebut.

admin_panel_settings

MODERATOR COMMANDS

Khusus Developer & Owner.

push_pin /pin MOD

Balas pesan lalu ketik /pin untuk pin pesan.

timer /setcd 5 MOD

Mengatur cooldown Global Chat dalam detik.

person_off /ban @username MOD

Ban user dari Global Chat.

person_add /unban @username MOD

Membuka kembali ban user.

campaign /all pesan MOD

Mengirim pengumuman untuk seluruh user.

delete_sweep /clear MOD

Membersihkan seluruh pesan Global Chat.

warning /warn @username pesan MOD

Mengirim peringatan moderasi kepada user.
